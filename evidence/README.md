# Evidence system

A roadmap is trustworthy only when completed work links to evidence.

## Categories

- **career/** - CV versions, interview scorecards, offer/onboarding notes, work-safe impact summaries
- **kibo-rpc/** - public-safe run summaries, lessons, release notes, and retrospective
- **english/** - speaking recordings index, interview answers, vocabulary reviews
- **portfolio/** - demos, case studies, screenshots, architecture notes
- **finance/** - private-safe summaries only; never commit bank details or sensitive personal documents

## Evidence entry format

Use [`../templates/evidence-entry.md`](../templates/evidence-entry.md) for every meaningful milestone.

> Do not commit passwords, API keys, private employer code, restricted Kibo material, identity documents, bank details, or sensitive family information.
