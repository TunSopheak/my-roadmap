# Reviews

Use reviews to update the roadmap from evidence rather than emotion.

- `weekly/` - execution, blockers, evidence, and next week's three must-wins
- `monthly/` - KPI review, budget progress, portfolio progress, and priority changes
- `yearly/` - annual outcomes, lessons, and next-year strategy

Suggested naming:

- `weekly/2026-W32.md`
- `monthly/2026-08.md`
- `yearly/2026.md`
